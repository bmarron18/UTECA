	google-genai 		<== most recent SDK for Google Gemini models

Notes: We will specify the use of python to create a virtual environment called, (ai-apis).
The virtual environment, (ai-apis), will be created with the Python package, "virtualenv"  using the command "venv". The virtual environment, (ai-apis), will be created in a sub-directory in Spyder. In Windows we will use python 3.14 in (ai-apis). in (ai-apis) you will see all python  distros. In MacOS use python 3.14 to create (ai-apis). In Linux use python 3.11-venv to create (ai-apis)

We will install special Python packages and SDK packages into the (ai-apis) virtual environment.


** Create the virtual environment, (ai-apis)
	- open a terminal in the "envs" directory of Spyder					<== Windows
		> C:\Users\<you>\AppData\Local\spyder-6\...\envs\>
	- type the following code to create (ai-apis)
		> py -m venv ai-apis


	- open a terminal in the "envs" directory of Spyder and create (ai-apis)		<== Linux
		$ python3.11 -m venv ./spyder-6/envs/ai-apis


** Activate the (ai-apis) virtual environment****
	- open a terminal in the "ai-apis\Scripts" directory of Spyder				<== Windows
		C:\Users\<you>\...\spyder-6\...\envs\ai-apis\Scripts>
	- type the following code to create (ai-apis)
		> activate
	- NB. When activated, you will see (ai-apis) at the command line
		(ai-apis)>
	- Keep this terminal open for the installation of special packages


		$ source ./spyder-6/envs/ai-apis/bin/activate					<== Linux/MacOS
		(ai-apis):~$
	- Keep this terminal open for the installation of special packages


** Installation of special packages****
	- type the following code to install special packages with the "pip" installer	<== Windows
		(ai-apis)> pip install spyder-kernels google-genai openai nltk jiter
	- Keep this terminal open for the deactivation of the virtual environment


	- type the following code to install special packages with the "pip" installer	<== Linux/MacOS
		(ai-apis):~$ pip install spyder-kernels google-genai openai nltk jiter		
	- Keep this terminal open for the deactivation of the virtual environment


** Deactivate and close the (ai-apis) virtual environment****
	- type the following code to deactivate and close the (ai-apis) virtual environment	<== Windows
		(ai-apis)> deactivate
	- NB. When deactivated, you will no longer see (ai-apis) at the command line
		>


	- type the following code to deactivate and close the (ai-apis) virtual environment	<== Linux/MacOS
		(ai-apis):~$ deactivate
	- NB. When deactivated, you will no longer see (ai-apis) at the command line
		$

PART VII
Notes on
Prompt Engineering
##################

*You could think about developer and user messages like a function and its arguments in a programming language.
    	-developer messages provide the system's rules and business logic, like a function definition.
    	-user messages provide inputs and configuration to which the developer message instructions are applied, like arguments to a function.
	- a prompt contains BOTH message types instructions: a) developer messages gives the model high-level instructions on how it should behave while generating a response, including tone, goals, and examples of correct responses. Any instructions provided this way will take priority over a prompt in the input parameter; b) user messages are strings of text, images, or file inputs to the model that are used to generate a specific response.
